# Modern Fitness CRM – README

A vibrant, modern CRM for personal trainers and fitness consultants. Features:
- Detailed client management (profile, goals, current activity, health info)
- Measurement tracking (weight, body metrics, body fat %, BMI, progress photos)
- Workout plans, attendance, sets/reps/weight, exercise videos
- Nutrition tracking (calories, macros, meal plans, water, supplements)
- Productivity and energy tracking (daily energy, productivity, sleep, stress, mood)
- Messaging for clients
- Nepali (BS) and English date support
- Achievement badges, reminders
- Dashboard analytics: active clients, check-ins, progress, sessions, achievements
- Export data/reports
- Monthly payment/quotation tracking (optional)
- Fitness-focused, energetic design (orange/red theme, optional dark mode)
